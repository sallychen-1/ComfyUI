# ComfyUI 圖生圖作業 / Website bài tập

Mở index.html để xem website. Không cần cài đặt hoặc build.

Đã thêm ảnh gốc, ảnh kết quả, screenshot workflow và JSON thực tế bạn cung cấp. Hai prompt được lấy từ các node nối vào positive/negative của KSampler trong workflow.json. Giữ nguyên phần 個人心得 đã cung cấp. Đổi màu khăn sang đỏ là mục tiêu; ảnh kết quả được giữ nguyên, không chỉnh sửa.

## GitHub Pages

Upload index.html, .nojekyll và thư mục assets/ vào gốc repository.
Vào Settings → Pages → Deploy from a branch → main → /(root) → Save.
Mở địa chỉ website GitHub cung cấp sau khi triển khai.

Website chưa được đăng lên GitHub.
